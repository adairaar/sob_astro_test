# TLG re-verification, 4 September 2026

Live re-run in TLG IRIS (MIT proxy), all 19 corpus authors loaded simultaneously
as a single search selection (125 works), results per page set to 500.

**Headline: the corpus counts in Table S8 are not lemma counts. The "Lemma"
search was returning a prefix match on the dictionary headword. Do not resubmit
until Feature A–D are recounted.**

---

## 1. The method error

TLG's Lemma radio, as driven by the protocol in `TLG_search_protocol.md`,
returns only wordforms that *begin with the headword string*. Demonstration on a
control verb:

| lemma searched | wordforms returned |
|---|---|
| λέγω | λέγω, λέγωμεν, λέγων, λέγωνται, λέγωσι, λέγωσιν |

λέγει, ἔλεγεν, εἶπεν, ἐλέχθη are all absent. A genuine lemma expansion returns
them. The same on the paper's own lemmas:

| lemma | wordforms actually retrieved |
|---|---|
| στηρίζω | στηρίζων, στηρίζωσι — only |
| προάγω | προαγωγ- forms + προάγων — **not** προῆγεν, Matthew's own form |
| ἔρχομαι | ἔρχομαι — only; **not** ἐλθών, Matthew's own form |

### The ἵστημι diagnosis was wrong
The recorded explanation — "TLG cannot expand -μι verbs morphologically" — is
not the cause. ἵστημι returns zero because **no word in the corpus begins with
the string ἵστημι**. It is the same prefix behaviour, not an athematic-verb
defect. Nothing about Feature B required a proxy lemma.

### Direct proof
Word Index (exact wordform) search, same 19-author corpus:

- **στηρίζει — 15 hits**, including Paul of Alexandria {2053.001} p.32 ll.1, 27
  and Theon {1724.001} pp.174, 190, both recorded in Table S8 as *0 hits*.

The lemma search found none of these.

### True size of the Feature B stem
Wildcard word-index search, στηρι*, filtered to the στηρίζω family:
**255 occurrences across 32 attested forms**, versus 17 recorded.

Includes the noun **στηριγμός** (~150 occurrences: στηριγμόν 33, στηριγμῶν 33,
στηριγμοῦ 29, στηριγμούς 24, στηριγμοί 17, στηριγμός 9, …) — the very term the
SI names as the technical word for a stationary point, never counted.
Also ἐστήρικται (10), ἐστήριξεν (3), στηρίζοντες (14), στηρίζοντος (11).

*Caveat*: 255 is across all works of all 19 authors. The corpus definition
restricts Aristotle to the Meteorologica and Theophrastus to De signis, so the
in-corpus figure will be lower. It will not be anywhere near 17.

## 2. A second, independent error: the 10-per-page cap

The original searches read only the first page of results. The tell is in
`TLG_search_protocol.md` Feature C, where Aristotle and Theophrastus are both
recorded with exactly **10** all-works hits. Ten was the page size.

Re-run with 500 per page, Feature C (ἐπάνω) gives **109 raw hits**, of which
**40 are in-corpus** — recorded as 29. The three Aristotle hits are in the
Meteorologica itself ({0086.026} at Bekker 375b28, 377a4, 377a6), contradicting
the note that "no Aristotle hit is in the Meteorologica."

## 3. A wrong author ID

`Theon of Smyrna {1358}` does not exist in TLG. The protocol flagged it
"unverified by autocomplete" and it was never corrected, so **Theon of Smyrna
was never searched**. The correct ID is **THEON Phil. {1724}**
(*De utilitate mathematicae*). {2033} is THEON Math. = Theon of *Alexandria*, a
different man.

Theon {1724} carries hits on three of the four features (στηρίζω ×1 by the old
method, στηρίζει ×2, ἐπάνω ×4).

## 4. An arithmetic slip

`TLG_search_protocol.md` Feature A states "Result: 9 in-corpus hits", but its own
per-author table reads Ptolemy 3 + Vettius Valens 4 + Hephaestion 3 +
Dorotheus 1 = **11**. The reproduction confirms the per-author figures exactly;
only the total was wrong. Table S8 has the same problem at Feature B, where the
listed Hephaestion locations sum to 11 but the count column says 10.

## 6. Direction of the error

Every correction found so far *increases* the corpus denominator, and no
Matthew-type positive has appeared in any newly recovered hit inspected so far.
If that holds after classification, each Fisher p falls:

| feature | N recorded | p recorded | N so far | p if all negative |
|---|---|---|---|---|
| A | 9 | 0.100 | ≥11 | ≤0.083 |
| B | 17 | 0.056 | ≫22 (stem 255) | ≪0.043 |
| C | 29 | 0.033 | ≥40 | ≤0.024 |
| D | 7 | 0.125 | ≥7, needs re-run | ≤0.125 |

**This is a correction that strengthens the result.** But it cannot be asserted
until every recovered hit has been read and classified, and the recount is a
larger job than the original: Feature B alone goes from 17 passages to a few
hundred.
